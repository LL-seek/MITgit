# 参数与 Flash 兼容合同（阶段 0）

版本：`legacy-parameter-contract/2026-08-28`  
证据源：`Config/user_config.h`、`PreferenceWriter/`、`FlashWriter/`、`main.cpp`。  
目标：让旧 Sector 6 数据能够被确定解释，并冻结新系统的兼容导入与安全保存策略。

## 1. 旧二进制布局

| 项 | 旧合同 |
|---|---|
| 存储区域 | STM32F446 内部 Flash Sector 6，`0x08040000～0x0805FFFF` |
| 实际使用长度 | 320 × 4 = 1,280 B，`0x08040000～0x080404FF` |
| Word 0～255 | `int32` 原始位模式，映射 `__int_reg[0..255]` |
| Word 256～319 | IEEE-754 binary32 原始位模式，映射 `__float_reg[0..63]` |
| 端序 | ARM 小端 |
| 对齐 | 32-bit word 对齐 |
| 旧记录头/版本/长度/CRC | **无** |
| 保存行为 | 每次 `open()` 整扇区擦除，随后顺序写 320 words |
| 成功判定 | 旧实现无逐字返回检查、无回读、无 CRC |

旧 ABI 中 ARMCC 的 `int` 和 `float` 都是 32 bit。新代码必须使用 `int32_t`、`uint32_t` 和显式 binary32 位拷贝，不得继续依赖本机 `int` 宽度或类型双关未定义行为。

## 2. 已知索引

### 2.1 整数区（Flash words 0～255）

| Flash word / `int` 索引 | 字段 | 单位/范围 | 旧启动默认/处理 | 迁移校验合同 |
|---:|---|---|---|---|
| 0 | `PHASE_ORDER` | 枚举 | 旧启动不校验 | 只接受 0 或 1，否则拒绝旧记录/进入安全默认 |
| 1 | `CAN_ID` | 0～127 | `-1` 时默认 1；错误地调用 `isnan(int)` | 0～127，默认 1 |
| 2 | `CAN_MASTER` | 0～255（CLI 文本曾显示 0～127） | `-1` 时默认 0 | 0～255，默认 0 |
| 3 | `CAN_TIMEOUT` | 0～100,000 control cycles | `-1` 时默认 0 | 0～100,000，默认 0 |
| 4～5 | 保留空洞 | 无 | 原样读写 | 导入时保留为 opaque；业务不得使用 |
| 6 | `RAW_OFFSET` | encoder count | 旧代码的 `isnan(int)` 无效 | 对 14-bit 编码器暂定 0～16,383；最终按实装器件 CPR 校验 |
| 7 | `RAW2_OFFSET` | encoder count | 同上 | 同上 |
| 8～135 | `ENCODER_LUT[0..127]` | signed correction count | 旧启动不逐项校验 | 长度必须 128；每项范围由阶段 5/8 依据实装编码器冻结 |
| 136～255 | 保留 | 无 | 原样读写 | 导入时保留为 opaque；新业务不得假设为零 |

### 2.2 浮点区（Flash words 256～319，`float` 索引 0～63）

| Flash word / `float` 索引 | 字段 | 单位/范围 | 旧启动默认/处理 | 迁移校验合同 |
|---:|---|---|---|---|
| 256 / 0 | `E_OFFSET` | electrical rad | NaN→0 | finite；按 `[0, 2π)` 归一化，默认 0 |
| 257 / 1 | `M_OFFSET` | mechanical rad | NaN→0 | finite；默认 0，范围由机械合同限制 |
| 258 / 2 | `I_BW` | Hz | NaN、-1 或 0→1000 | 100～2000，默认 1000 |
| 259 / 3 | `I_MAX` | A | NaN、-1 或 0→12；再限幅 0～12 | 0～12，默认 12；0 是否允许须由 App 状态明确 |
| 260 / 4 | `THETA_MIN` | rad | 旧启动未校验，当前未发现有效消费 | 保留导入但首版不发布给控制器，待产品需求确认 |
| 261 / 5 | `THETA_MAX` | rad | 同上 | 同上；若启用必须满足 finite 且 min≤max |
| 262 / 6 | `I_FW_MAX` | A | NaN 或 -1→0；再限幅 0～12 | 0～12，默认 0 |
| 263～319 / 7～63 | 保留 | 无 | 原样读写 | 导入时保留原始 32-bit words，不解释 NaN payload |

“保留 opaque”是为了使导入工具可审计和可逆，不表示这些未知字段可以直接进入控制器。

## 3. 旧格式判定与导入顺序

新固件加载顺序固定为：

1. 在 Sector 6/7 中查找并验证新格式 A/B 记录；
2. 若没有任何有效新记录，尝试把 Sector 6 开头 320 words 按本文件旧布局解析；
3. 对所有已知字段执行类型、有限性、枚举和范围校验；
4. 只有整体满足最低安全条件时才导入；不能把随机 Flash 或半写记录当作有效旧参数；
5. 导入到 `MotorParameters` 后设置“需要升级保存”事件，但启动阶段不直接擦写；
6. 若旧格式无效，使用带诊断原因的安全默认值；
7. 在安全状态完成首次新格式 A/B 保存并回读 CRC 后，才认为升级成功。

由于旧布局没有 magic/CRC，识别必须保守。最低整体条件至少包括：`PHASE_ORDER∈{0,1}`、CAN 字段在范围内、所有实际使用浮点数 finite 且在范围内、两个 raw offset 与实装 CPR 一致、LUT 通过阶段 5/8 的合理性检查。任何关键字段失败时不得“只修坏字段后假装整记录可信”；应记录拒绝原因并采用默认值或经批准的字段级恢复策略。

## 4. 新记录兼容策略（已冻结的边界）

阶段 8 负责确定具体结构体，但以下边界在阶段 0 已冻结：

- 程序区只能是 `0x08000000～0x0803FFFF`；链接器不能进入参数区；
- Sector 6 (`0x08040000`) 为参数 A，Sector 7 (`0x08060000`) 为参数 B；
- 新头至少包含 `magic`、`version`、`payload_size`、`sequence`、payload CRC 和提交状态；
- 所有字段固定宽度、显式小端，结构大小与关键偏移有静态断言；
- 以有效 CRC 和最高 sequence 选择最新完整记录；写失败时旧记录仍有效；
- 新格式必须保存语义字段，而不是让 Control/CAN/Encoder 继续访问魔法数组索引；
- 保留旧原始记录的导入测试向量；升级只能单向发生一次，仍可通过离线工具解释原始 320 words；
- Flash HAL 只接受 Sector 6/7 的明确绝对地址，并检查写入对齐、边界、返回码、回读和 CRC。

## 5. 保存状态机合同

允许的唯一顺序：

```text
请求保存
  → 拒绝新 MOTOR 请求/请求退出 MOTOR
  → 输出进入 COAST，确认 TIM1 功率输出关闭
  → 停止 40 kHz 控制发布并确认无 Flash 中执行路径
  → 选择非当前有效 A/B 扇区
  → 擦除、写头/载荷/CRC、最后提交
  → 逐字节回读并复算 CRC
  → 成功：切换 active sequence；失败：保留旧记录
  → 恢复到 REST（不得自动重新进入 MOTOR）
```

禁止在 ISR、MOTOR 有效状态、PWM 未确认关闭或电源故障过程中擦写。CAN 特殊帧和 CLI 只能投递保存请求，不能直接调用 Flash。

## 6. 已知旧缺陷对合同的影响

- D-009：旧 linker 允许程序覆盖 Sector 6；阶段 1 必须限制 IROM 为 256 KiB。
- D-019：`__SECTORS[5]` 错写为 `FLASH_Sector_6`；新 HAL 实现不用此表，并做绝对地址白名单。
- D-020：旧主循环可在 MOTOR 运行时响应 CAN 保存请求并整扇区擦写；新状态机禁止。
- D-022：旧数据无 CRC/版本，且对 `int` 调用 `isnan`、多个字段不做范围检查；新加载器 fail-closed。

## 7. 阶段 8 必须保留的测试向量

1. 全 `0xFF` 的擦除 Sector；
2. 一份真实或合成的有效 320-word 旧记录；
3. 每个关键字段分别损坏、NaN、Inf、越界的旧记录；
4. 只写一半的旧记录；
5. A 有效/B 无效、A 无效/B 有效、两者有效 sequence 不同、sequence 回绕；
6. 擦除前、擦除中、写头、写 payload、写 CRC 和提交前后的掉电点；
7. MOTOR 状态保存请求被延迟且不发生 Flash 操作；
8. 写入 Sector 0～5 或范围外地址被 HAL 拒绝。
